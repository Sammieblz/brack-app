| `components/MobileLayout.tsx` | Existing measured-header/footer focus revelation also runs on keyboard/programmatic focus entry. Focus entry during an active pointer contact does not trigger this added reveal; owner/header/pinch guards and cleanup remain explicit. |

Comment-range refresh adds requests proportional to the previously opened range and newly arriving comments; hidden threads pause those reads. This trades extra reads for coherent retained task ownership, without changing server/API pagination contracts.

Direct-message text storage now uses `message_draft_${currentUserId}_${conversationId}`. Legacy unscoped keys remain untouched and are not loaded because their reader ownership is unknown. Media uploads already started cannot be cancelled by the current service interface; failed/abandoned uploads may leave storage objects. Retry identity is component-memory state, not a process-persistent delivery queue. No backend, database, dependency, route identity, theme, font or icon-library changes.
